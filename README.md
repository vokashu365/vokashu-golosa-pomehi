# Голоса Найт-Сити: Помехи

Угон передвижной студии, конвой через руины Пасифики, кулачный бой за проезд, сделка с гаитянскими нетраннерами и концерт под ударом «Милитеха» на шестидесятой минуте. Самый громкий из пяти ваншотов. 4–5 часов, 3–5 эджраннеров любых ролей.

«Голоса Найт-Сити» — пять независимых ваншотов про первые за полвека выборы мэра в Найт-Сити осенью 2070 года, сразу после Войны за объединение. Их можно играть по одному, в любом порядке или кампанией: общий журнал объясняет, что творится в городе, а счётчик явки и эпилог «Ночь выборов» сводят истории вместе.

## Установка

**По манифесту.** Foundry VTT → «Дополнения» → «Установить модуль», вставьте в поле «Ссылка на манифест»:

```
https://github.com/vokashu365/vokashu-golosa-pomehi/releases/latest/download/module.json
```

**Вручную.** Скачайте `vokashu-golosa-pomehi.zip` из [релизов](https://github.com/vokashu365/vokashu-golosa-pomehi/releases) и распакуйте в `Data/modules/`.

**Импорт.** Включите модуль в мире на системе Cyberpunk RED — CORE, откройте компендиум «Голоса Найт-Сити: Помехи — приключение целиком» и нажмите «Импортировать». Журналы, сцены, персонажи и предметы разложатся по папкам «Голоса Найт-Сити». Начните с журнала «00 · Перед стартом игры».

Если ставите несколько историй из серии в один мир, импортируйте их по очереди: общий журнал и общие персонажи (Райн, Холт, Сорель) у всех модулей одни и те же и не задвоятся.

Требования: Foundry VTT 12, система Cyberpunk RED — CORE 0.92 или новее. Другие модули и DLC не нужны.

## Что внутри

- Журналы для ведущего: подготовка, кто есть кто, ведение по шагам с текстом для чтения вслух и репликами, персонажи, финалы, раздатки для игроков.
- Сцены-карты с сеткой и сцены-арты для каждой локации. На каждой сцене — заметка для ведущего «Что здесь происходит» (игроки её не видят).
- Персонажи с заполненными листами, портретами и токенами.
- Уникальные предметы и архитектуры Сети.
